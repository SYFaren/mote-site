Linux / Unix

X11, Wayland, SDL2, консоль TTY и framebuffer.

  • mote-linux-x11 — X11 GUI
  • mote-linux-wayland — Wayland
  • mote-linux-sdl2 — SDL2
  • mote-linux-console — TTY
  • mote-linux-fbdev — /dev/fb0

Windows

GDI‑окно и отдельная консольная сборка.

  • mote-windows-gui.exe — GUI
  • mote-windows-console.exe — console

DOS

FreeDOS / DOSBox, сборка DJGPP, текстовый VGA.

  • mote-dos.exe

WebAssembly

Один архив mote-web.zip: распакуйте и откройте mote.html через локальный HTTP‑сервер.

  • mote-web.zip — html + js + wasm + data

Или всё сразу по папкам: mote-all-platforms.zip
