mote

Крошечный консольный текстовый редактор на ANSI C89. Подсветка синтаксиса, поиск с regex, вкладки, восстановление после сбоя. Без зависимостей.

Tiny console text editor written in ANSI C89. Syntax highlighting, regex search, tabs, crash recovery. No dependencies.

Проверено на Linux; другие POSIX-системы могут работать, но не тестируются. Windows — консольная сборка (MinGW-w64).

Verified on Linux; other POSIX systems may work but are untested. Windows build is console-only (MinGW-w64).

Из исходников:

From source:

git clone https://github.com/SYFaren/mote
cd mote
make            # POSIX
make windows    # Windows console (MinGW-w64)

Возможности

Features

  • До 6 документов, быстрое открытие (Ctrl+P), недавние файлы
  • Безопасное сохранение и восстановление несохранённого после сбоя
  • UTF-8, LF/CRLF, явное открытие Windows-1251
  • Undo/redo, автоскобки, автоотступ, комментирование, закладки
  • Поиск и замена, regex /шаблон/
  • Подсветка: C/C++, Python, JS/TS, Go, Rust, Java, shell, SQL, PHP, JSON, HTML, CSS, Markdown, YAML, Make
  • Темы: тёмная, светлая, slate
  • Up to 6 documents, quick open (Ctrl+P), recent files
  • Safe save and recovery of unsaved work after a crash
  • UTF-8, LF/CRLF, explicit Windows-1251 import
  • Undo/redo, auto-close, auto-indent, toggle comment, bookmarks
  • Find and replace, regex /pattern/
  • Highlighting: C/C++, Python, JS/TS, Go, Rust, Java, shell, SQL, PHP, JSON, HTML, CSS, Markdown, YAML, Make
  • Themes: dark, light, slate
